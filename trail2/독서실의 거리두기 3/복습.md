# 문제 제목

## **📝문제 설명**
신종 전염병이 퍼짐으로써 리브로스 독서실은 이용자들의 좌석 간의 거리를 두려고 합니다. <br/>
새로 한 명을 더 받으려고 하는데, 현재 있는 사람들은 원래 있던 자리에 그대로 두고 최대한 거리를 두면서 자리배치를 해주려고 합니다. 여기서 거리라 함은, 두 사람이 몇 칸 떨어져 있는지를 의미합니다. <br/>
리브로스 독서실에 있는 모든 좌석의 개수가 N개이고, 현재 좌석의 공석 여부가 주어지면, 한 명의 인원을 배치한 후 최대한의 거리두기를 실행한 간격을 출력하는 프로그램을 작성해보세요. <br/>
최대한의 거리두기를 한다는 것은, 한 명을 더 집어넣었을 때 가장 가까운 두 사람 간의 거리를 최대로 하고 싶다는 뜻입니다. 단, 양쪽 끝자리에는 항상 사람이 앉아있는 상태로 주어짐을 가정해도 좋습니다.<br/>
첫 번째 줄에 가능한 가장 가까운 두 사람의 거리의 최댓값을 출력하세요.<br/>
### **⚠제한사항**
- 3 < N < 1000<br/>
- 주어지는 문자열은 0과 1으로만 주어집니다.<br/>
  
### **입출력 예**
- 젓 번째 줄에 좌석의 개수 n이 주어집니다<br/>
- 두 번째 줄에 길이가 N이고 0, 1로 이뤄진 문자열이 하나 주어집니다. <br/>
- 0이면 비어있음, 1이면 이미 자리가 차 있음을 의미합니다. <br/>

```
12
100010010001
```
## **🧐CODE REVIEW**


### **🧾나의 풀이**

```js
const fs = require("fs");
const input = fs.readFileSync(0).toString().trim().split('\n');
const n = Number(input[0]);
const seats = input[1].split("").map(Number);

let maxMinDist = 0

for (let i = 0; i < n; i++) {
    if (seats[i] === 0) {
        // 비어있는 자리다
        seats[i] = 1

        //현재 배치 상태에서 가장 가까운 두 사람 간의 거리를 구한다
        let minDist = Infinity;
        let lastOneIdx = -1;
        for (let j = 0; j < n; j++) {
            if (seats[j] === 1) {
                if (lastOneIdx !== -1) {
                    minDist = Math.min(minDist, j - lastOneIdx);
                }
                lastOneIdx = j;
            }
        }
        maxMinDist = Math.max(maxMinDist, minDist)
        seats[i] = 0
    }
}

console.log(maxMinDist)
```

3. 지금 상태에서 가장 가까운 두 사람 사이의 거리를 구한다<br/>
   1과 1 사이의 거리가 가장 가까운 거리의 간격을 구한다<br/>
   특히, 지금 1의 값이 나온 사람과, 그 직전에 1이 나온 사람 사이의 거리를 구한 뒤, <br/>
   지금까지 발견한 사람 간의 거리 중 가장 가까운 거리 min로 정의한다.
   lastOneIndex를 -1로 정의해두어서, 0번째 인덱스에 해당하는 사람은 자신과의 거리를 구하는 오류가 발생할 수도 있으므로 -1로 해둠
   즉, -1이 아니다라는 뜻은 이전에 1을 발견한 사람이 이미 최소 1명 있다는 뜻
   
```js
let minDist = Infinity;
let lastOneIndex = -1;

for(let j = 0; j < n; j++){
  if(seats[j] === 1){
    if(lastOneIndex !== -1){
      minDist = Math.min(minDist, j - lastOneIndex);
    }
    lastOneIndex = j
  }
}
maxMinDist = Math.max(maxMinDist, minDist)
seats[i]=0
```

### **다른 풀이**
```
const fs = require("fs");
const input = fs.readFileSync(0).toString().trim().split('\n');

const INT_MAX = Number.MAX_SAFE_INTEGER;

// 변수 선언 및 입력
const n = Number(input[0]);
const seats = input[1].split("").map(Number);

// Step1. 최적의 위치 찾기
// 인접한 쌍들 중 가장 먼 1간의 쌍을 찾습니다.
let maxDist = 0;
let [maxI, maxJ] = [-1, -1];
for (let i = 0; i < n; i++) {
    if (seats[i] === 1) {
        for (let j = i + 1; j < n; j++) {
            if (seats[j] === 1) {
                // 1간의 쌍을 골랐을 때
                // 두 좌석간의 거리가 지금까지의 최적의 답 보다 더 좋다면
                // 값을 갱신해줍니다.
                if (j - i > maxDist) {
                    maxDist = j - i;

                    // 이때, 두 좌석의 위치를 기억합니다.
                    [maxI, maxJ] = [i, j];
                }

                // 인접한 쌍을 찾았으므로 빠져나옵니다.
                break;
            }
        }
    }
}

// Step2. 최적의 위치에 1을 놓습니다.
// 가장 먼 쌍의 위치 가운데에 놓으면 됩니다.
const mid = maxI + Math.floor(maxDist / 2);
seats[mid] = 1;

// Step3. 이제 인접한 쌍들 중 가장 가까운 1간의 쌍을 찾습니다.
// 이때의 값이 답이 됩니다.
let ans = INT_MAX;
for (let i = 0; i < n; i++) {
    if (seats[i] === 1) {
        for (let j = i + 1; j < n; j++) {
            if (seats[j] === 1) {
                ans = Math.min(ans, j - i);

                // 인접한 쌍을 찾았으므로 빠져나옵니다.
                break;
            }
        }
    }
}

console.log(ans);
```

#### **📝해설**

* 인접한 1의 쌍 중에서, 가장 거리가 먼 쌍의 가운데에 1을 두는 것이 문제에서 원하는 최대한의 거리두기를 실행한 간격을 구하는 전략이다.<br/>
* 가장 거리가 먼 1의 쌍을 찾았다면, 그 1 사이 중 가운데에 새 사람을 앉힌다. <br/>
<br/>

1. 입력을 받는다.<br/>
   js에서 안전하게 표현할 수 있는 가장 큰 정수 값을 INT_MAX라는 변수에 저장한다.<br/>
   
```js
const fs = require("fs");
const input = fs.readFileSync(0).toString().trim().split('\n');
const INT_MAX = Number.MAX_SAFE_INTEGER;
```

2. 첫 번째 줄에 입력받은 n 값은 n 변수에 저장합니다.<br/>
   두 번째 줄에 입력 받은 0,1로 이뤄진 배열은 seats 배열에 저장합니다.<br/>
   
```
const n = Number(input[0]);
const seats = input[1].split("").map(Number);
```

3. 인접한 쌍들 중 가장 먼 1간의 쌍을 찾습니다.<br/>
   먼저 배열을 순회하면서 1을 찾고, i +1 부터 순회하며 두 번째 1의 값이 나온 j 값을 찾는다.<br/>
   만약 j - i 즉 두 1 사이의 거리가 maxDist보다 크다면, 이 값으로 갱신합니다.<br/>
   그리고 이에 해당하는 j, i 값을 인덱스로 저장한다.<br/>
   1과 1로 이루어진 한 쌍을 찾을 때, 우리는 그 사이가 0으로만 차 있는 값을 찾으므로 break가 j값을 하나라도 찾으면 필요하다.<br/>
   
```
let maxDist = 0;
let [maxI, maxJ] = [-1, -1];
for (let i = 0; i < n; i++) {
    if (seats[i] === 1) {
        for (let j = i + 1; j < n; j++) {
            if (seats[j] === 1) {
                // 1간의 쌍을 골랐을 때
                // 두 좌석간의 거리가 지금까지의 최적의 답 보다 더 좋다면
                // 값을 갱신해줍니다.
                if (j - i > maxDist) {
                    maxDist = j - i;

                    // 이때, 두 좌석의 위치를 기억합니다.
                    [maxI, maxJ] = [i, j];
                }

                // 인접한 쌍을 찾았으므로 빠져나옵니다.
                break;
            }
        }
    }
}
```

4. 최적의 위치에 1을 놓는다.<br/>
   즉, 가장 먼 쌍의 위치 가운데에 둔다. 값이 소수점이 나올수도 있으므로 `Math.floor`을 적용한다.<br/>
   
```
const mid = maxI + Math.floor(maxDist / 2);
seats[mid] = 1;
```

5. 다시 배열을 순회하면서, 인접한 1의 쌍 중 그 사이의 거리가 가장 가까운 1쌍을 찾는다.<br/>
   그 쌍 사이의 거리가 답이다.<br/>
   지금 찾는 거리는 1의 쌍 중 그 사이의 거리가 최소인 걸 찾는다.<br/>
   
```
const mid = maxI + Math.floor(maxDist / 2);
seats[mid] = 1;

let ans = INT_MAX;
for (let i = 0; i < n; i++) {
    if (seats[i] === 1) {
        for (let j = i + 1; j < n; j++) {
            if (seats[j] === 1) {
                ans = Math.min(ans, j - i);

                // 인접한 쌍을 찾았으므로 빠져나옵니다.
                break;
            }
        }
    }
}
```
