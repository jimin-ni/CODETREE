# 문제 제목

## **📝문제 설명**
N 개의 수가 주어졌을 때, 두 번째로 작은 수의 위치를 출력하는 프로그램을 작성해보세요.
<br>
### **⚠제한사항**
- 2 <= N <= 100 
- 1 <= 주어지는 정수 <= 100
  <br>
### **입출력 예**
첫 번째 줄에 정수 N이 주어집니다.<br>
두 번째 줄에 N개의 정수가 공백을 사이에 두고 주어집니다.
```
5
1 1 1 2 1
```
<br>
첫 번째 줄에 두 번째로 작은 수의 위치를 출력합니다. <br>
여기서, 첫 번째 원소의 위치를 1로 생각합니다.<br>
단, 두 번째로 작은 수가 없거나 여러 개 있는 경우에는 -1로 출력합니다.
`4`
<br>

#### **😅개선점**

1. sort() 메서드는 원본 배열을 변형한다. <br>
   내가 따로 배열을 선언해 이를 저장해도, 최초의 a배열은 이미 훼손된 상태이다.<br>
2. 두 번째로 작은 수(`secSmallest = sorArr[1]`)를 선언하는 방식은 중복된 수가 있을 경우를 고려하지 못한다.<br>
3. 중복 개수 카운트 내부의 오타 (a[i] vs a[j])
4. count 변수가 1이 되어야 원하는 정답에 해당함. 0이면 모든 경우에 결과가 -1로 나온다.

### **다른 풀이**

```js
const fs = require("fs");
const input = fs.readFileSync(0).toString().trim().split("\n");

const n = Number(input[0]);
const a = input[1].split(" ").map(Number);

// 중복을 제거하고 오름차순으로 정렬하여 '진짜' 두 번째로 작은 수 찾기
const uniqueSorted = [...new Set(a)].sort((x, y) => x - y);

if (uniqueSorted.length < 2) {
    console.log(-1);
    process.exit(0);
}

const secSmallest = uniqueSorted[1];

let count = 0;
let targetIndex = -1;

for (let i = 0; i < n; i++) {
    if (a[i] === secSmallest) {
        count++;
        targetIndex = i + 1; 
    }
}


if (count === 1) {
    console.log(targetIndex); 
} else {
    console.log(-1); 
}

```

#### **📝해설**

1. a 배열을 오름차순으로 정렬하고, 중복을 제거해 uniqueSorted 이름으로 저장한다. <br>
  set 은 원본배열의 원소를 가져와서 중복을 제거한 set 객체를 새로 만든다.
```js
const uniqueSorted = [...new Set(a)].sort((x, y) => x - y);
```<br>
2. 만약 정렬한 배열의 길이가 1 또는 0이라면, 중복되어 n개의 수가 있는 것으로 실제 수의 종류는 1개 이하이므로 두 번째로 작은 수가 없다.<br>
   때문에 -1을 저장하고 구문을 종료한다.
```
if (uniqueSorted.length < 2) {
    console.log(-1);
    process.exit(0);
}
```<br>
3. 정렬한 배열의 두 번째 원소가 두 번째로 작은 수이다.
```
const secSmallest = uniqueSorted[1];
```<br>
4. 원본 배열을 순회하면서 두번째로 작은 수가 중복되는지 검사한다.<br>
  중복된다면 count 변수에 그 중복 횟수를 저장한다.<br>
  원본배열에서 해당 수의 indext에 1을 더한 값을 저장한다. <br>
  (문제에서 각각의 수는 1번부터 시작한다고 했으므로 1 더함)
```
let count = 0;
let targetIndex = -1;

for (let i = 0; i < n; i++) {
    if (a[i] === secSmallest) {
        count++;
        targetIndex = i + 1; 
    }
}
```<br>
5. count의 수를 세어서 1이라면 중복이 없으므로 원하는 수이다.<br>
  다른 경우는 중복된 경우 등에 해당하므로 -1을 출력한다.
```
if (count === 1) {
    console.log(targetIndex); 
} else {
    console.log(-1); 
}
```<br>

### **🔖정리**

1. sort 메소드는 원본 메소드를 오름차순 정렬한다.
2. new Set 을 이용해서 원본 배열을 가져와 중복제거한 새로운 Set 객체를 만든다.
