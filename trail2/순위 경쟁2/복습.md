# 문제 제목

## **📝문제 설명**
2명의 학생 A, B가 각자 게임을 합니다. 게임 결과에 따라 점수를 얻을 수도 있으며, 잃을 수도 있습니다. </br>
이 게임은 특이하게 게임 점수가 바뀔 때마다 점수가 1등인 사람들을 모아 명예의 전당에 그 이름을 올려줍니다. </br>
점수 변동 관련 정보가 주어졌을 때, 명예의 전당에 올라간 사람의 조합이 총 몇 번 바뀌었는지를 출력하는 프로그램을 작성해보세요. </br>
</br>
### **⚠제한사항**
- $1 \le N \le 100</br>
- $$-100 \le s \le 100$</br>
- $c$는 'A', 'B' 중 하나입니다.</br>
### **입출력 예**
첫 번째 줄에는 점수 변동 목록의 수 $N$이 주어집니다.</br>
두 번째 줄 부터는 $N$개의 줄에 걸쳐 점수 변동 관련 정보 $c$, $s$가 공백을 사이에 두고 주어집니다. </br>
$c$는 'A', 'B' 중 하나이며 학생에 대한 정보를 나타냅니다. </br>
$s$는 점수 변동값을 의미합니다.두 학생의 점수는 처음에 전부 $0$임을 가정해도 좋습니다.</br>
</br>
**입력**
```
7
A -1
B 1
A 1
A 1
B 2
B 1
A 4
```
</br></br>
**출력**
```
4
```
</br>

### **🧾나의 풀이**

```js
const fs = require('fs');
const input = fs.readFileSync(0).toString().trim().split('\n');

const n = Number(input[0])
const changes = input.slice(1).map(line => line.split(' '))

// 학생별 누적 점수 기록 
let scoreA = 0
let scoreB = 0

// 현 시점 점수가 가장 높은 사람
let winner = ''

// 바로 직전까지 점수가 가장 높았던 사람
let lastTurnWinner = ''

// 1등 변동 횟수
let chg = 0

// 점수를 비교해서 더 높은 점수를 가진 쪽에 winner 이름 넣기
function whoIsWinner(scoreA, scoreB) {
    if (scoreA > scoreB) {
        winner = 'A'
    } else if (scoreA < scoreB) {
        winner = 'B'
    } else {
        winner = ' '
    }

    return winner
}

for (let i = 0; i < n; i++) {
    let [name, chg] = changes[i]
    if (name === 'A') {
        scoreA += chg
        let win = whoIsWinner(scoreA, scoreB)

        if (win !== lastTurnWinner) {
            chg++
        }
        lastTurnWinner = win

    } else if (name === 'B') {
        scoreB += chg

        let win = whoIsWinner(scoreA, scoreB)

        if (win !== lastTurnWinner) {
            chg++
        }
        lastTurnWinner = win
    }
}

console.log(chg)
```

### **다른 풀이**

```js
const fs = require('fs');
const input = fs.readFileSync(0).toString().trim().split('\n');

const n = Number(input[0])
const changes = input.slice(1).map(line => line.split(' '))

// 학생별 누적 점수 기록 
let scoreA = 0
let scoreB = 0

// 바로 직전까지 점수가 가장 높았던 사람
let lastTurnWinner = 'AB'

// 1등 변동 횟수
let count = 0

// 점수를 비교해서 더 높은 점수를 가진 쪽에 winner 이름 넣기
function whoIsWinner(scoreA, scoreB) {
    if (scoreA > scoreB) {
        return 'A'
    } else if (scoreA < scoreB) {
        return 'B'
    } else {
        return 'AB'
    }
}

for (let i = 0; i < n; i++) {
    let [name, chg] = changes[i]
    const value = Number(chg);

    if (name === 'A') {
        scoreA += value
    } else if (name === 'B') {
        scoreB += value
    }

    const currentWinner = whoIsWinner(scoreA, scoreB);

    if (currentWinner !== lastTurnWinner) {
        count++;
        lastTurnWinner = currentWinner;
    }
}

console.log(count)
```
